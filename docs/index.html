Code source sur GitHub

Parle.
Ton texte s'écrit tout seul.

Une dictée vocale pour Windows qui fonctionne dans tous tes logiciels. La reconnaissance tourne sur ton PC, sans rien envoyer sur internet.

Maintiens Ctrl + Espace, parle, relâche.
Télécharger pour Windows Guide d'installation

Pensée pour aller vite

Tu parles trois à quatre fois plus vite que tu ne tapes. Dictée enlève tout ce qui se met entre ta voix et ton texte.

Partout

Discord, navigateur, Word, éditeur de code, jeux en fenêtré : le texte arrive là où se trouve ton curseur.

En direct

Une bulle en verre affiche ce que tu dis au fur et à mesure, et le texte est collé une à deux secondes après le relâchement.

Privée

Le modèle Whisper d'OpenAI tourne sur ton processeur. Ta voix ne quitte jamais ton ordinateur.

Légère

Environ 80 Mo de mémoire au repos. Le modèle n'est chargé que pendant que tu dictes.

Installation en trois étapes

Il faut Windows 10 ou 11 et Python 3.10 ou plus récent.

1

Installer Python

Depuis python.org. Coche « Add python.exe to PATH » pendant l'installation.

2

Télécharger Dictée

Récupère le ZIP avec le bouton en haut de cette page, puis décompresse-le où tu veux.

3

Lancer l'installation

Double-clique sur installer.bat. Quelques minutes plus tard, l'icône apparaît près de l'horloge.

Réglable en une ligne

Tout se règle dans %APPDATA%\Dictee\config.json : la langue, la taille du modèle, et les mots rares que tu veux voir bien orthographiés.

{
  "modele": "small",
  "langue": "fr",
  "vocabulaire": "Discord, Kubernetes, Jean-Baptiste",
  "garder_modele_secondes": 60
}
